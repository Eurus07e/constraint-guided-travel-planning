# Paper

- [`constraint_contract_multi_agent_repair.pdf`](constraint_contract_multi_agent_repair.pdf): final 16-page course paper.
- [`source/`](source/): LaTeX source, bibliography, style file, generated tables, and figures needed to rebuild the paper.

Build from the `paper/source` directory with:

```bash
latexmk -pdf -interaction=nonstopmode travelplanner_course_report.tex
```

The paper was prepared as the final project for *Introduction to Artificial
Intelligence* at Nanjing University. It is a course artifact, not a peer-reviewed
publication.
